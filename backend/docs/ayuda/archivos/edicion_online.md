# Abrir y editar documentos en línea

Los documentos compatibles pueden abrirse mediante INTASA Cloud.

## Edición

Al pulsar la opción de edición online, el Portal abre el editor correspondiente.

Guarda los cambios dentro del editor antes de cerrar.

## Versiones

Cuando el sistema utiliza versionado, una nueva actualización puede conservar la referencia lógica del documento y aumentar su versión.

## Problemas de apertura

Comprueba:

- que el documento terminó de subirse;
- que el formato es compatible;
- que tienes permiso;
- que la sesión de INTASA Cloud está disponible.

# Subir una carpeta completa

La función **Elegir carpeta** permite importar una carpeta y conservar su estructura interna.

## Antes de ejecutar

El Portal realiza una previsualización o comprobación previa.

Revisa:

- carpeta raíz;
- subcarpetas;
- número de archivos;
- nombres;
- posibles omisiones;
- empresa y destino.

## Ejecutar

Confirma la carga únicamente cuando la previsualización sea correcta.

No cierres el navegador mientras se está ejecutando.

## Resultado

Al terminar, revisa el resumen de archivos creados, omitidos o pendientes.

Si aparece una incidencia, no vuelvas a subir toda la carpeta sin comprobar primero qué elementos ya fueron creados.

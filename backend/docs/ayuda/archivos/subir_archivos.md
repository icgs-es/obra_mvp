# Subir un archivo

## Procedimiento

1. Abre la carpeta de destino.
2. Comprueba la empresa seleccionada.
3. Pulsa la opción de subir archivo.
4. Selecciona el documento.
5. Confirma la operación.
6. Espera el mensaje final antes de cerrar la página.

## Comprobación

Después de subirlo, verifica:

- nombre;
- carpeta;
- empresa;
- tamaño;
- versión;
- posibilidad de abrirlo.

No repitas inmediatamente la operación si la carga tarda. Espera la respuesta del Portal.

# Organización de carpetas y archivos

El módulo Archivos organiza la documentación mediante carpetas y subcarpetas.

## Empresa

Los documentos pueden estar vinculados a una empresa.

Antes de subir o mover información, comprueba la empresa documental activa.

## Almacenamiento

El Portal puede mostrar documentos almacenados localmente o mediante **INTASA Cloud**.

La ubicación técnica no cambia la forma habitual de consultar el documento.

## Nombres

Utiliza nombres claros que permitan reconocer el contenido sin abrirlo.

Evita nombres genéricos como `documento.pdf` o `archivo nuevo`.

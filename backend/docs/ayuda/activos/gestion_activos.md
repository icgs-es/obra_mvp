# Gestión de activos

El módulo Activos centraliza el inventario autorizado.

## Consulta

Utiliza los filtros y la búsqueda para localizar el activo por nombre, código, tipo o responsable.

## Información

Comprueba datos como:

- identificación;
- estado;
- ubicación;
- gestor actual;
- origen de sincronización;
- observaciones.

Los cambios deben mantener la trazabilidad del activo y su responsable.

# Tareas

Las tareas convierten una necesidad en una acción identificable y trazable.

## Información recomendada

- título claro;
- responsable;
- fecha prevista;
- empresa;
- prioridad;
- descripción;
- estado.

## Seguimiento

Actualiza el estado cuando la tarea comienza, queda bloqueada o termina.

Una tarea terminada no debe mantenerse como pendiente.

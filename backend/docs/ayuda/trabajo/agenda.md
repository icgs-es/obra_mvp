# Agenda

La Agenda organiza eventos y compromisos del Portal.

## Crear un evento

Indica al menos:

- título;
- fecha;
- hora cuando corresponda;
- empresa o ámbito;
- descripción útil.

## Consultar

Utiliza las vistas y filtros disponibles para revisar eventos próximos o pasados.

Antes de crear un evento duplicado, busca por fecha y título.

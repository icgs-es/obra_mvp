# Registrar una salida de gasoil

La salida de gasoil debe reflejar el consumo real entregado a un vehículo.

## Datos principales

- almacén;
- recurso gasoil;
- cantidad en litros;
- vehículo de destino;
- fecha;
- observación cuando sea necesaria.

## Resultado

La operación crea una salida y reduce el stock correspondiente.

Antes de guardar, comprueba especialmente los litros y el vehículo.

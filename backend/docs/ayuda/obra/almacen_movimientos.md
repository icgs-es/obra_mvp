# Movimientos de almacén

Los movimientos modifican o explican el stock disponible.

## Tipos habituales

- entrada;
- salida;
- rotura;
- regularización autorizada.

## Datos a comprobar

- recurso;
- almacén;
- cantidad;
- unidad;
- fecha;
- origen;
- destino;
- observación.

## Pendiente de partida

Un movimiento puede quedar pendiente de imputar a una partida.

Debe completarse cuando se conozca el destino real para conservar la trazabilidad económica.

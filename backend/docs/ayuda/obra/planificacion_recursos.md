# Planificación de recursos

Los recursos pueden ser previstos o reales y pertenecer a distintos tipos.

Entre ellos:

- material;
- herramienta;
- maquinaria;
- mano de obra;
- equipos de protección;
- portes.

## Asignación

Comprueba siempre:

- obra;
- tarea;
- fechas;
- cantidad u horas;
- recurso;
- responsable.

## Previsto y real

El previsto representa la planificación.

El real representa el consumo, trabajo o coste finalmente registrado.

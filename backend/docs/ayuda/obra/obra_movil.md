# Obra móvil

Obra móvil está diseñada para registrar operaciones desde el lugar de trabajo.

## Funciones

Puede incluir:

- producción;
- movimientos de almacén;
- stock rápido;
- historial;
- gasoil;
- incidencias.

## Recomendaciones

Comprueba la obra, recurso y cantidad antes de guardar.

Evita repetir una operación si la conexión es lenta. Espera la confirmación o consulta el historial.

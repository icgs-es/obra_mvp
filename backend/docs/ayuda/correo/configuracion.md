# Correo no habilitado

El botón flotante solo aparece cuando la cuenta está preparada para utilizarse.

La configuración puede requerir:

- cuenta activa;
- dirección válida;
- verificación completada;
- configuración IMAP y SMTP;
- credencial disponible para la conexión.

## Qué hacer

La configuración debe revisarla una persona autorizada.

No introduzcas contraseñas corporativas en formularios distintos de los previstos para la configuración del correo.

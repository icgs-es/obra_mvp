# Correo corporativo

El correo puede abrirse desde el menú **Trabajo** o mediante el botón flotante.

## Ventana flotante

La ventana permite consultar la bandeja sin abandonar la pantalla de trabajo.

Puede:

- abrirse;
- minimizarse;
- moverse en escritorio;
- actualizarse;
- cerrarse.

En móvil ocupa la pantalla para facilitar la lectura.

## Mensajes no leídos

El distintivo del botón informa del número aproximado de mensajes pendientes de lectura.

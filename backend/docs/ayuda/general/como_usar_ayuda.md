# Cómo utilizar la ayuda

Pulsa el botón verde con el símbolo **?** que aparece en la parte inferior de la pantalla.

## Buscar una explicación

Escribe una duda utilizando palabras sencillas:

- autorizar factura
- subir una carpeta
- registrar un pago
- consultar una tarea

La ayuda utilizará también la pantalla en la que te encuentras para priorizar las explicaciones relacionadas.

## En ordenador y móvil

En un ordenador, la ayuda se abre como un panel lateral.

En un teléfono o tableta, se abre a pantalla completa para que el texto y el teclado sean cómodos.

## Privacidad y permisos

La ayuda solo muestra los artículos correspondientes a los módulos que el usuario tiene autorizados.

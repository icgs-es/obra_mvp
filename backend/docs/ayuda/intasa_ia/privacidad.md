# Privacidad de las conversaciones de INTASA IA

Las conversaciones pertenecen al usuario que las crea.

## Acceso normal

Otro usuario no puede consultar una conversación privada salvo que:

- se comparta expresamente;
- disponga de un permiso administrativo específico;
- sea superusuario.

## Información sensible

No incluyas contraseñas, claves API, certificados privados ni credenciales.

INTASA IA debe trabajar únicamente con la información necesaria para resolver la consulta.

# Compartir una conversación de INTASA IA

El propietario puede conceder acceso a otro usuario autorizado.

## Tipo de acceso

El acceso compartido es de lectura.

El destinatario puede consultar la conversación, pero no escribir nuevos mensajes dentro de ella.

## Retirar acceso

El propietario puede retirar el acceso compartido.

La conversación continúa perteneciendo a su creador.

# Gestión de leads

Un lead representa un contacto u oportunidad comercial que necesita seguimiento.

## Registro

Incluye datos suficientes para identificar:

- persona o empresa;
- medio de contacto;
- fuente;
- interés;
- activo relacionado cuando corresponda;
- próximas acciones.

## Seguimiento

Actualiza el estado y las observaciones después de cada contacto.

La información debe ser concreta y útil para la siguiente persona que consulte el lead.

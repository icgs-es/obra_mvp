# Enviar líneas de albarán a almacén o partida

Las líneas de un albarán pueden destinarse a almacén o imputarse directamente a una partida o tarea.

## Distribución parcial

Una cantidad puede dividirse entre varios destinos.

La suma de las cantidades asignadas no puede superar la cantidad de la línea documental.

## Estado de asignación

El Portal puede mostrar:

- **NO:** no hay cantidad asignada;
- **PARCIAL:** solo se ha asignado una parte;
- **SÍ:** toda la cantidad está distribuida.

## Trazabilidad

La operación mantiene la relación entre el albarán original y los movimientos o imputaciones creados.

# Adjuntar el PDF de una factura

En el detalle de la factura puede añadirse el documento original y sus anexos.

## Procedimiento

1. Selecciona el tipo de documento.
2. Elige el archivo PDF.
3. Pulsa **Adjuntar PDF**.
4. Espera la confirmación antes de abandonar la página.

## Recomendaciones

- utiliza el PDF original recibido;
- evita adjuntar el mismo documento varias veces;
- comprueba que el archivo corresponde a la empresa y proveedor correctos;
- conserva anexos relevantes como certificaciones o justificantes.

El documento adjunto no sustituye a los datos registrados en la factura, pero permite comprobar su origen.

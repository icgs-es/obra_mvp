# Catálogo de proveedores

El catálogo centraliza los datos utilizados en facturas y albaranes.

## Buscar

Puede buscarse por nombre, nombre fiscal, CIF, teléfono o correo electrónico.

## Antes de crear

Comprueba variantes del nombre y el CIF para evitar duplicados.

## Datos principales

Mantén actualizados:

- nombre comercial;
- razón fiscal;
- CIF;
- teléfono;
- correo electrónico;
- dirección;
- ámbito de gestión.

Modificar un proveedor no elimina sus documentos históricos.
